2. Information Collection and Storage

Zero Data Transmission: Calculator Bit does not collect, store, transmit, or share any personal information, usage metrics, or sensitive device information. All computational inputs and outputs are processed locally within your device's memory.

Because the Application does not capture or process personal data, we do not share, sell, or rent user information to any third parties.

3. Local Application State

To provide a consistent and personal user experience, Calculator Bit may store certain configuration settings locally on your Windows device, including:

  • Display preferences (e.g., active application theme and layout choice)

This data is written strictly to local application sandbox directories using standard Windows API protocols. This information remains isolated on your local machine, is not transmitted to external network locations, and is completely deleted when you uninstall the Application.

4. Network Connectivity and Third-Party SDKs

Calculator Bit operates as a self-contained, offline application. It does not require network access to execute its features or resolve mathematical operations.

To prevent data leaks and maintain complete user privacy, the Application does not integrate any third-party telemetry frameworks, external analytics libraries, proprietary diagnostics Software Development Kits (SDKs), or background reporting services.

5. Device Capabilities and Permissions

The Application's packaging manifest does not declare or request access to any sensitive Windows platform capabilities. Specifically, Calculator Bit does NOT require access to:

  • Your geographical location
  • Your microphone, camera, or hardware peripherals
  • Your local files, contacts, calendar, or external documents
  • The active internet connection

Because Calculator Bit is an offline mathematical tool that collects no data, it is safe for users of all ages, including children under the age of 13. The Application complies fully with the Children's Online Privacy Protection Act (COPPA) and corresponding international data privacy laws.
