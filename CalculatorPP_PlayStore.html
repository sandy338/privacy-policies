2. About SmartCalculator

SmartCalculator is a feature-rich calculator application designed to work entirely offline. The application does not require an internet connection to perform calculations and operates independently on your device. The only exception is for crash reporting and app analytics through Firebase Crashlytics, which helps us improve the application's stability and user experience.

3. Information We Collect

SmartCalculator collects minimal information. Here's what we collect:

3.1 Crash Reports (Firebase Crashlytics)

When the application crashes or encounters an error, we collect crash data through Firebase Crashlytics. This data includes:

  • Stack traces and error logs
  • Device information (device model, OS version, RAM)
  • Application version and build information
  • Timestamp of the crash
  • Diagnostic information

Important: We do NOT collect:

  • Any calculation results or input data
  • Personal identifying information (name, email, phone number)
  • Location data
  • Contact lists or personal files
  • Browsing history or usage patterns

3.2 Local Storage

SmartCalculator stores certain user preferences locally on your device, such as:

  • Display preferences (themes, language settings)
  • Application settings

This data is stored entirely on your device and is never transmitted to our servers.

4. How We Use Your Information

The information we collect is used solely for the following purposes:

  • Improving Stability: Crash reports help us identify and fix bugs to provide a stable application
  • Performance Optimization: We analyze crash data to optimize application performance
  • Application Enhancement: Understanding errors helps us develop better features
  • Technical Support: Crash information assists us in resolving issues reported by users

5. Firebase Crashlytics and Data Processing

SmartCalculator integrates Firebase Crashlytics, a service provided by Google LLC, to collect crash reports and improve application reliability.

5.1 Firebase Data Collection

Firebase Crashlytics automatically collects crash data, including:

  • Crash stack traces
  • Device information
  • Application version information
  • Timestamps

5.2 Data Security

Firebase Crashlytics data is transmitted to Google's secure servers using encrypted connections. For more information about Google's privacy practices and how they handle this data, please refer to:

  • Firebase Privacy and Security
  • Google Privacy Policy

5.3 Data Retention

Crash data collected by Firebase Crashlytics is retained according to Google's retention policies. Typically, this data is retained for a limited period (usually 90 days) before being automatically deleted.

6. Offline Functionality

SmartCalculator is designed to work completely offline. No internet connection is required for the core calculation functionality. The application will function fully without any network connectivity, and no data from your calculations is ever transmitted online or stored on remote servers.

7. Permissions

SmartCalculator may request the following Android permissions:

  • Internet Permission: Used exclusively for Firebase Crashlytics crash reporting
  • Network State Permission: To determine network status for crash report delivery

These permissions are used only for the stated purposes. We do not use them to transmit any calculation data or personal information.

8. Data Sharing and Third Parties

We do not sell, trade, or rent your personal information to any third parties. However, we do share crash data with:

  • Firebase Crashlytics (Google): For crash reporting and app stability analysis

We do not share calculation results, preferences, or any other data with third parties.

9. Data Security

We implement appropriate technical and organizational measures to protect your data:

  • All data transmitted to Firebase Crashlytics is encrypted in transit
  • Local storage on your device uses standard Android security mechanisms
  • We do not implement unnecessary data collection practices

While we strive to protect your information, no security system is impenetrable. We cannot guarantee absolute security of your data.
